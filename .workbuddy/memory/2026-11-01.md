## get-aoi P1/P2 改进（性能 + 功能扩展）

### P1 性能
1. **并发抓取**：新增 `utils/ratelimit.py`（RateLimiter 线程安全预约式限流）；`HttpClient` 支持共享 `limiter`；`cli.py` 改 `_provider_factory`（每 worker 独立 Session）+ `_iter_pois` 用 ThreadPoolExecutor；`request.concurrency`（默认 1）+ CLI `--concurrency`。AntiBotError 时 cancel 其余 future 并落盘。
2. **边界缓存**：新增 `core/cache.py`（BoundaryCache，sqlite + 线程锁），`fetcher.fetch` 集成（命中后回填 name/type/address）；`cache.enabled`/`cache.dir`（默认 ~/.cache/get_aoi）。跨次运行复用边界。
3. **检索翻页**：高德 `place/text` 翻 page（每页 25）、百度 `place/v2/search` 翻 page_num（每页 20），跨页累计 source_rank，取满 max_candidates 或无更多即停。

### P2 功能
4. **MultiPolygon 中心**：`geometry_center` 改为取面积最大部件算中心（新增 `_poly_area_km2`），避免多校区合并时中心落到空地。
5. **坐标逆变换**：`utils/coords.py` 补 LL2MC 算法（`bd09_to_bd09mc`），convert_point 补全 wgs84/gcj02/bd09/bd09mc 两两互转；convert `--to` 增加 bd09mc。
6. **结果报告**：新增 `exporters/csv.py`（export_summary_csv + export_attributes_csv），`outputs.report`（默认 true）导出 summary.csv + aoi_attributes.csv。

### 关键约定（易踩）
- RateLimiter「预约时隙」：锁内只更新 `_last_ts`、锁外 sleep，`_last_ts` 初始 0（epoch 远小于 now）使首请求不 sleep。
- 缓存 key = `provider|poi_id`；缓存存回填后的完整 AOIRecord，命中时用当前候选名覆盖。
- 翻页停页条件：`len(结果) < page_size` 或 `len(候选) >= needed`。
- cmd_run 的 `finally` 负责 `cache.close()`（except 分支里不要再 close，会二次 close 抛异常）。
- 测试脚本临时目录清理时 run.log 句柄未释放会报 PermissionError（既有行为，真实 CLI 单进程单 run，退出即释放，非 bug）。

### 验证
- 70 个单测全绿（新增 test_cache/test_pagination/test_report + 补 test_coords 往返/MultiPolygon 中心、test_cli convert bd09mc、test_config concurrency/cache/report）。
- 端到端 mock：并发 2、缓存二次运行 fetch_calls=0、summary.csv + aoi_attributes.csv + aoi.geojson(3 features) 齐全。
- `convert --crs wgs84 --to bd09mc`、`estimate --concurrency 4` 均验证通过。
- bd09↔bd09mc 往返误差 <2cm（LL2MC 精确）；wgs84→bd09mc 误差 ~1.8m（来自 gcj02/wgs84 近似逆变换的固有米级误差）。

## keep_types 支持二级分类匹配

`filter_candidates` 的白名单由「仅第一级精确匹配」改为「任一级命中即保留」。

### 改动
- `filter.py`：新增 `_type_levels(poi_type)`（按 `;`/`|` 拆各级、去空段与首尾空格）；白名单改 `not (set(levels) & keep)`；`keep` 集合对各项 strip（修掉逗号后空格的坑）。黑名单仍按一级分类精确排除（语义不变）。
- 文档：config.py / example.yaml / README 的 keep_types 注释由「一级分类白名单」改为「分类白名单，任一级命中即保留」。

### 关键约定（易踩）
- 高德 type 形如 `大类;中类;小类`（如 `商务住宅;住宅区;住宅小区`），百度 classified_poi_tag 形如 `金融;银行;ATM`、tag 形如 `金融;atm`；第一段才是一级分类，二级/三级在 `;` 后续段。
- 现在可直接填二级词（如 `住宅区`、`银行`）；一级词仍照常生效。
- 百度「交通设施」「出入口」是一级分类但被内置黑名单 DEFAULT_EXCLUDE_TYPES 拦（黑名单独立于白名单）。
- 百度 POI 行业分类表（lbsyun 官方 poitags 文档）左列=一级、右列=二级；一级可直接填，二级现在也可填。

### 验证
- 新增 tests/test_filter.py 的 TestKeepTypesLevels 8 用例（二级/一级/三级命中、`|` 分隔、未命中淘汰、keep_types 带空格 strip、空 poi_type、keep_types=None）。
- 全量 78 单测全绿（原 70 + 新 8）。
